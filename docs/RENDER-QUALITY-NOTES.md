# 实时渲染质感经验：从"塑料件"到"真实材质"

> 沉淀自 AETHERKEEP 云际圣堡（`handoff/plans/CLOUDCASTLE-02.md` 规划的一次完整实现）。
> 结论先行：**质感不是靠贴更多贴图，是靠层次；塑料感不是靠分辨率低，是靠"完美"。**

---

## 0. 一句话

> 塑料模具件的质感，来自于它**只有一个表面层、并且完美重复**。
> 真实材质是**多层叠加**的，而且**每一块都不一样**。

所有具体手法都只是这两句话的推论。

---

## 1. 四层叠加模型

真实的石墙、金属、布料，至少同时具备四层信息。缺任何一层都会立刻"塑料"。

| 层 | 内容 | 缺了会怎样 |
|---|---|---|
| **L1 低频形体** | 轮廓不是数学上完美的面（凿痕、起伏、磨损棱角） | 边缘高光一条直到底 → 立刻"模压件" |
| **L2 中频几何** | 真实凹陷：窗洞、砌缝、铆钉、榫卯 | 平面上的阴影线索缺失 → 像贴纸 |
| **L3 单元级随机** | 每块砖/每颗铆钉独立的大小、色偏、磨损 | 完美重复 → 墙纸感 |
| **L4 高频表面** | 颗粒、法线起伏、粗糙度变化 | 反光均匀 → 塑料感的最大单一来源 |

**本项目的落实**：L1 = 几何顶点扰动（世界坐标，共享顶点不撕裂）；L2 = 真凹拱窗 + 券石 + 扶壁；L3 = 逐砌块哈希色差 + 灰缝加深；L4 = AI albedo + 离线推导的 normal/roughness。

---

## 2. 塑料感的 5 个可检查来源（排查清单）

按这个顺序查，通常 80% 的"塑料感"来自前两条。

1. **高光是均匀的** —— roughness 是常数，或没有独立 roughness 通道。**最致命**。
2. **图案完美重复** —— 同一张贴图在每个构件上 1:1 重复，看得出周期。
3. **贴图密度随构件大小变化** —— 同一张石纹在 44m 宽的墙和 0.36m 高的檐口上砖缝差几十倍。
4. **形体是完美平面/柱面** —— 边缘高光没有断点。
5. **没有接触关系** —— 物体与地面、物体与物体之间太干净，没有 AO、投影、碎屑、积灰。

## 3. 关键手法与其代价

| 手法 | 收益 | 代价 / 陷阱 |
|---|---|---|
| **AI 生成 PBR 贴图** | 天然带"这面墙被造出来过"的不完美——程序化噪声做不出这种痕迹 | 不可控：出图可能跑偏（曾出过高饱和锈红砂岩，与整体冷调冲突，必须返工） |
| **逐单元哈希色差（世界坐标）** | 每块砖独立色偏/亮度，1:1 消灭重复感 | 必须用**世界坐标**，不能用物体局部坐标，否则构件一动纹理就滑 |
| **顶点扰动** | 轮廓不再刀切，高光会断 | 必须在**索引几何**上做（共享顶点不撕裂）；非索引几何（Extrude/Polyhedron）上做会把面撕开 |
| **几何细分 + 扰动** | 扰动有足够顶点承载 | 三角形数暴涨（本项目 282k → 373k），注意 draw call 与三角形预算 |
| **独立 roughness 通道** | 消除"均匀反光"这个塑料感最大来源 | roughness 贴图是**线性数据**，不能设 sRGB |
| **真凹几何（而非贴图假窗）** | 掠射光下有真实自阴影 | 几何量与合批复杂度上升；用材质分桶 + `mergeGeometries` 合并 |
| **AO + 阴影 + 碎屑** | 建立接触关系 | AO 不能"干脆不要"，宁可降采样数 |
| **大气透视** | 让物体"在世界里"而不是"在桌上" | 最便宜却最容易被忽略的一步 |

## 4. 本项目实际踩过的 8 个坑（都是通用教训）

| # | 现象 | 根因 | 教训 |
|---|---|---|---|
| 1 | 地面发黑、崖壁发白，像贴反了 | 三角形**绕序反了**，`computeVertexNormals` 算出朝内的法线 | 法线方向问题先查绕序，不要先怀疑光照 |
| 2 | 板岩屋顶压成死黑 | 顶点色用了**材质本色**，与贴图**双重相乘** | 顶点色只做**轻微色调**；贴图已是最终颜色 |
| 3 | 坡屋顶变成伸出去的平板 | 旋转符号写反，屋面朝上翘 | 旋转方向用"法线指向"验算，别靠试 |
| 4 | 云是一张灰白噪点毯 | 密度量级错：光学厚度 σ∫ρds 爆掉，整条路径不透明 | 体积渲染先算**光学厚度量级**，再调密度 |
| 5 | bloom 出现反馈回路警告 | `EffectComposer` 的 `renderTarget2 = renderTarget.clone()` **共享同一个 depthTexture** | 自己管渲染目标，每个 pass 的读写目标严格分离 |
| 6 | 砖缝在墙上和檐口上差几十倍 | 几何体原生 UV 是"每面 0..1"，密度随构件大小漂移（实测跨度 **67 倍**） | 密度一致性要用**米/UV单位**量化，不要目测 |
| 7 | 合并后的几何整块消失 | `mergeGeometries` 要求**索引状态一致**，混合 indexed/non-indexed 会**静默返回 null** | 合并前统一转非索引并校验属性集 |
| 8 | 塔尖被画面裁掉 | 取景用包围盒**角点**投影，角点含"远侧高处"等不存在的组合，跨度被高估 | 量主体占比要**采样真实轮廓点**，不是包围盒角点 |

## 5. 从"好看"到"可判定"

质感如果只能靠感觉，就没法迭代、没法验收、没法交接。本项目把"好看"拆成了可测指标：

| 指标 | 阈值 | 抓的是什么 |
|---|---|---|
| 灰度直方图非零桶数 | ≥200 | 画面有没有**连续的色调层次**（压平成灰白会立刻掉到个位数） |
| 亮度 P99−P1 | ≥0.55 | 有没有**真正的明暗动态范围** |
| HSV 饱和度中位 | ≥0.12 | 有没有**整体去色** |
| 两块真实云 ROI 亮度差 | ≥0.12 | 云有没有**受光/背光分离**（防"白棉花"） |
| draw calls / 三角形 | ≤120 / ≤1.5M | 性能预算 |
| 边界 RGB 差（贴图接缝） | ≤0.06 | 贴图能不能无缝平铺 |

**关键：ROI 判定要取"最暗的合格区域"，不是"刚过阈值的区域"。** 后者会把指标做得比实际容易通过。

## 6. 值得做 / 不值得做

**值得**（投入产出比高）：
- 逐单元世界坐标色差（一层 shader，改动小、收益大）
- 独立 roughness 通道
- 顶点扰动（配合细分）
- 接触关系：AO + 墙脚碎屑
- 量化指标 + 真实浏览器截图回归

**不值得**（性价比低或风险高）：
- 真 IBL / 探针反射（成本高，收益在这个尺度上看不出来）
- 次表面散射、各向异性 BRDF（除非材质真的需要）
- 为"更精致"去堆后期特效（一旦过曝，全盘皆输；后期是最容易掩盖建模缺陷的层）
- 全分辨率景深（日常关闭即可，四分之一分辨率够用）

---

## 7. 迭代顺序（重要）

```
先修几何与法线 → 再修贴图密度与材质 → 再修光照/AO → 最后才动后期
```

**顺序反了就会被后期掩盖问题，最后返工成本最高。** 当你发现"怎么调光都不对"时，通常错的是法线或绕序，不是曝光。

---

## 8. 一句话记忆

> 模具件是**一个人造的、完美的、只有一层的东西**。
> 要让它像真的，就给它**层次**，再让它**每一块都不一样**，最后让它**和周围发生关系**。
